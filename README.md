# رحلة قطّورة: تحدّي الخيمة والزيتون

نشاط تفاعلي في **دورة المياه في الطبيعة** • العلوم والحياة • الصف الرابع الأساسي

إعداد: **مها السيلاوي** • إشراف: **د. مجدي عقل**

## محتوى المشروع

- **التصميم الجيد:** عشرة أنشطة بتسعة أنماط تفاعل (تجربة محاكاة، تصنيف، توصيل، ترتيب، تسمية مخطط، إكمال فراغ، صح أم خطأ، اختيار متعدد، اختيار من متعدد). الصف كله فريق واحد: كل نشاط محلول يحوّل خيمة إلى بيت، وكل حلّ من المحاولة الأولى يُسقط حبة زيتون على الكوفية. يتضمّن فيديو «رحلة قطّورة» وتلميحات ومحاولة ثانية وتقريراً للمعلّمة وبطاقة خروج.
- **التصميم السيئ:** المحتوى العلمي نفسه بأخطاء تصميم مقصودة، للنقد والتحليل التربوي فقط.
- **المقارنة بين التصميمين:** مقارنة تفصيلية في ٢١ معياراً موزّعة على ستة مجالات: لكل معيار ما يفعله التصميم الجيد وما يفعله السيئ، وأثر ذلك في التعلّم، مع المرجع العلمي.

## طريقة التشغيل

- **دون إنترنت:** نزّلي `water-cycle-offline.html` وافتحيه بالمتصفح (يُفضّل Chrome أو Edge).
- **رابط على الويب:** من إعدادات المستودع ← Pages ← اختاري الفرع `main` والمجلد `/ (root)`، فيصبح النشاط متاحاً على رابط GitHub Pages.
